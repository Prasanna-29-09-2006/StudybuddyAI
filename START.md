# Study Buddy AI - Quick Start Scripts

## Start Backend
```powershell
& "backend\maven\apache-maven-3.9.6\bin\mvn.cmd" -f backend\pom.xml spring-boot:run
```

## Start Frontend
```powershell
cd frontend; npm run dev
```

## Access the App
- Frontend: http://localhost:5173
- Backend API: http://localhost:8080/api
